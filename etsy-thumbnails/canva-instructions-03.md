# Product 3 — Coloring Pages: Export & Delivery Instructions

## What You Have
`sellable-03-coloring-pages.html` — 20 kawaii coloring pages (5 fully drawn SVGs + 15 themed placeholders) with a browsable gallery and print button. Buyers open in Chrome and print directly.

## How to Export as Individual PNGs (300 DPI)

### Method — Canva
1. Open Canva → Create Design → Custom Size → 2550 x 3300px (Letter at 300dpi)
2. Upload your SVG: Upload → Upload files → select the SVG
3. Resize to fill the canvas
4. Export: Download → PNG → 300 DPI
5. Repeat for each page

### Method — Inkscape (Free, Best Quality)
1. Download free Inkscape app
2. Open each SVG in Inkscape
3. File → Export PNG → 300 DPI → Export As
4. Name: `01-sleepy-cat.png`, `02-happy-bear.png` etc.

## How to Package for Etsy

### Create the ZIP
1. Create a folder: `Kawaii-Coloring-Bundle`
2. Inside, create subfolders: `PNG-Files/`, `PDF-Bundle/`, `Instructions/`
3. Put all 20 PNG files in `PNG-Files/`
4. Combine PNGs into one PDF using ilovepdf.com → PNG to PDF
5. Save as `Complete-Coloring-Bundle.pdf` in `PDF-Bundle/`
6. Create a simple `README.txt` in `Instructions/` with printing tips
7. Right-click the main folder → Send to → Compressed folder

### Upload to Etsy
- Max file size: 20MB. If larger, use Google Drive link delivered via PDF
- Upload the ZIP as your digital download

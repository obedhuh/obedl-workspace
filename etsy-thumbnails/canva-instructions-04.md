# Product 4 — SVG/PNG Clipart Bundle: Export & Delivery Instructions

## What You Have

## How to Export Each SVG as PNG (for buyers who want PNG)

### Method — Canva (Easiest, No Software Required)
1. Open Canva → Upload → Upload files → select the SVG file
2. Place on canvas (any size — SVG scales perfectly)
3. Download → PNG → check "Transparent background"
4. Done — 300 DPI transparent PNG ready to use

### Method — Inkscape (Free, Best Quality)
1. Download Inkscape (inkscape.org)
2. File → Open → select SVG
3. File → Export PNG Image → set 300 DPI → Export As
4. Name: `01-rosa-garden.png`, `02-peony-blush.png`, etc.

### Method — Adobe Illustrator
1. Open SVG → File → Export → Export As → PNG
2. Set resolution to 300 DPI, check Transparent background

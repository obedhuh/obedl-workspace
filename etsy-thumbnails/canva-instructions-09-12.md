# Products 9-12 — POD Physical Products: Delivery Instructions

Products 9–12 are print-on-demand listings. You are NOT delivering a digital file to buyers — you print and ship via Printify/Printful automatically.

---

## Product 9 — May Birth Flower Mug (sellable-09-may-flower-mug.html)

### Your Design File
`sellable-09-may-flower-mug.html` contains the full Lily of the Valley mug wrap design as an SVG. Download it and export as PNG.

### Export Process
1. Open the HTML file in Chrome
2. Click "Download SVG Design"
3. Open SVG in Inkscape → File → Export PNG → 300 DPI → Export As
4. Name: `may-birth-flower-mug-design.png`

### Upload to Printify
1. Printify → Products → All-Over-Print Mug → Choose 11oz
2. Upload Design → drop your PNG
3. Resize to fill the print template area
4. Set price (cost ~$8, sell for $18-24)
5. Publish → connects to your Etsy listing automatically

### Etsy Listing Details
- Title: "May Birth Flower Mug | Lily of the Valley Coffee Mug | May Birthday Gift | Botanical Floral Mug"
- Price: $18-24 (Printify handles printing + shipping)
- Tags: may birthday, birth flower mug, lily of the valley, botanical mug, floral coffee mug, may gift
- Do all 12 birth months = 12 listings, same effort, 12x sales potential

## Product 12 — Personalized Mama Mug (thumbnail-12.html)

### Special Note — Personalized Products
This is a PERSONALIZED listing. Buyers message you with their kids' names, and you create a custom version for each order.

### Setup
1. Create a template design in Canva:
   - "Mama" in script at top
   - Hearts and floral garland
   - Leave a space for names to be added
2. When an order comes in:
   - Duplicate the template
   - Add the buyer's kids' names
   - Download → Upload to Printify → Submit order manually

### Etsy Listing Setup
1. When creating the listing: Personalization → Enable → Required
2. Add the prompt: "Enter up to 4 children's names, separated by commas"
3. Upload the base template image as your listing photo

### Printify Workflow for Custom Orders
1. Buyer purchases and sends names via Etsy message
2. You edit the Canva template with their names
3. Go to Printify → manually create order → upload their custom design
4. Submit the order → Printify prints and ships directly to buyer

### Pricing
- Base price: $22-28
- This is your highest-margin product if you batch orders (10-20/week)

### Etsy Title
"Personalized Mama Mug | Kids Names Mug | Custom Mom Coffee Mug | Mother's Day Gift | Personalized Mom Gift | Baby Names Mug"

## General POD Tips

### Pricing Formula
- Printify/Printful cost × 2.5 = your retail price
- Example: $8 mug cost → sell at $20-22

### Always Order a Sample First
- Order 1 unit of each product before publishing
- Check print quality, color accuracy, and fit
- Takes 5-7 days — do this before going live

# Product 1 — Digital Planner: Export & Delivery Instructions

## What You Have
- `sellable-01-planner.html` — fully functional planner with 5 tabs, daily/weekly/monthly pages, goals, and notes

## How to Export as PDF (for Etsy delivery)

### Option A — Chrome Print to PDF (Free, Recommended)
1. Open `sellable-01-planner.html` in Google Chrome
2. Click each section tab (Daily, Weekly, Monthly, Goals, Notes)
3. For each section: press `Ctrl+P` → Set destination to "Save as PDF"
4. Settings:
   - Paper size: Letter (8.5 x 11in) or A4
   - Margins: None
   - Scale: 100%
   - Check "Background graphics"
5. Save each section as a separate PDF:
   - `planner-daily-2026.pdf`
   - `planner-weekly-2026.pdf`
   - `planner-monthly-2026.pdf`
   - `planner-goals-2026.pdf`
   - `planner-notes.pdf`
6. Combine with free tool: **ilovepdf.com → Merge PDFs** into one file
7. Final file: `All-in-One-Digital-Planner-2026-2028.pdf`

### Option B — Canva (Better visual quality)
1. Go to Canva → Create Design → Custom Size → 2550 x 3300px (letter at 300dpi)
2. Recreate page templates using the HTML as your design guide
3. Use Canva's "Add page" to add all pages in sequence
4. Export: Download → PDF Print → Flatten PDF OFF (keeps quality)

## How to Make It GoodNotes Compatible
1. Export the PDF using Option A above
2. Open GoodNotes → Import → select your PDF
3. It works immediately as a digital notebook
4. For hyperlinks: use Canva Pro export with links enabled, OR Adobe Acrobat to add hyperlink buttons

## Hyperlinking Tabs (Professional Version)
1. Export base PDF from Chrome
2. Open in Adobe Acrobat (free trial works)
3. Tools → Edit PDF → Link → Add/Edit Web or Document Link
4. Draw box over each tab button → Link to page number
5. Re-export as PDF

## How to Deliver on Etsy
1. Zip the final PDF: right-click → Send to → Compressed folder
2. Upload to Etsy listing as digital file (max 20MB — use ilovepdf.com to compress if needed)
3. Buyers receive the download link immediately after purchase

## Pricing Note
Price at $12–$19. Add "Instant Download" prominently in your listing title. Mention GoodNotes + Notability compatibility in your description.

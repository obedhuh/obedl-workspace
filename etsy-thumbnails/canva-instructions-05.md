## How to Create Real Canva Templates

### Step 1 — Build 1 Template Per Niche (10 total)
1. Open Canva → Create Design
2. Pick a size: Instagram Post (1080×1080), Story (1080×1920), Pinterest (1000×1500)
3. Design a clean, professional template in that niche's style
4. This becomes your "master" — duplicate it for variations

### Step 2 — Get Shareable Template Links
1. In Canva, open your template
2. Click **Share** (top right) → **More** → **Template link**
3. Or: Share → Copy link → change `/edit` to `/template/copy` in the URL
4. When someone clicks this link, Canva prompts them to "Use template" — creates their own copy

### Step 3 — Replace Links in the HTML File
In `sellable-05-plr-templates.html`, find every `https://canva.com/design/new` and replace with your real Canva template links.

Use a text editor (VS Code, Notepad++):
- Find: `https://canva.com/design/new`
- Replace each one with the appropriate Canva template link

# Project Context

## About Me
- Complete beginner to programming
- Understands basic concepts like variables and functions

## The Project: Macro Tracking App

### Requirements
- Runs in the browser (HTML, CSS, JavaScript in a single file)
- No frameworks, no installs
- Users can type in a food name + protein, carbs, fat, calories
- Add food to a daily log
- Automatically calculates and displays running daily totals
- Users can set a daily calorie and macro goal
- Shows progress toward hitting goals
- Users can delete individual meals from the log

### Approach
- Build step by step
- Explain overall structure in plain English first
- Write HTML structure first, explain each part
- Then add JavaScript logic, explaining each function
- Explain reasoning behind each decision
- Use comments in the code
- Prioritize clarity over cleverness
- Prefer simple over "correct but complex" — explain trade-offs
- End with one small feature suggestion for the user to try adding themselves
